## 2. 공통 요소

### 2.1 레이아웃

```
┌──────────────────────────────────────────────────────────────┐
│ [로고] 가격추적      대시보드  상품  수집상태      [+ 상품등록] │
├──────────────────────────────────────────────────────────────┤
│  (샘플 모드 배너) ⓘ 현재 샘플 데이터를 표시하고 있습니다.        │
├──────────────────────────────────────────────────────────────┤
│                         본문                                  │
└──────────────────────────────────────────────────────────────┘
```

- 샘플 배너는 화면에 샘플 데이터가 하나라도 있을 때 표시한다.
- 모바일(< 640px): 상단 메뉴는 햄버거로 접는다. PC와 노트북 브라우저가 주 사용 환경이다.

### 2.2 상태 배지 (색상 + 텍스트 함께 표시)

| 배지 | 조건 | 표시 예 |
|---|---|---|
| `정상` | 24시간 안에 성공 수집 | 초록 · "정상" |
| `오래됨` | 마지막 성공이 24시간보다 오래됨 | 노랑 · "3일 전 데이터" |
| `수집 실패` | 마지막 시도가 실패 | 빨강 · "수집 실패 (3회 연속)" |
| `데이터 부족` | 30일 또는 90일 통계 조건 미달 | 회색 · "데이터 부족 · 20일 수집" |
| `샘플` | source = sample | 보라 · "샘플" |
| `수동` | source = manual | 테두리만 · "수동 입력" |
| `AI 해석` | ai_insights 카드 | 별도 아이콘 + "AI 해석" |

### 2.3 가격 표기 규칙

- 금액: `89,000원` (천 단위 쉼표)
- 비교: `최저가 대비 +6.0%` 또는 `수집 기간 최저가와 동일`
- 날짜: `2026-11-18 14:30 (KST)` 형식. 상대 시간("3시간 전")은 툴팁으로 절대 시간 함께 제공
- "역대 최저가"라는 표현은 쓰지 않는다. **"수집 기간 최저가"**만 쓴다

### 3.7 가격 알림 `/alerts` — P2 (자리만)

조건 목록(목표가 이하, 수집 기간 최저가 갱신, N% 하락)과 발생 이력. MVP에서는 메뉴에 표시하지 않는다.

- 판매가는 상품 카드의 `data-price`(쿠폰·적립 혜택가 아님). 새 상품은 색상 페이지마다 상품 1개, 옵션 "전체 옵션" 1개.

### 3.9 상세 화면 추가 요소 — 구현 후 추가

- **판매처·색상별 가격 비교** (판매처 2개 이상): 현재가, 수집 기간 최저가, 마지막 기록, 상태, "● 가장 저렴"
- **자동 요약** (점선 카드, "규칙 기반 · AI 아님"): 통계 숫자로 만든 문장, 근거 범위
- **가격 알림** (관리자): 목표가 저장/삭제, 도달 여부
- **최근 수집 기록 → 무효 처리** (관리자): 사유 입력, 되돌릴 수 없음

## 6. 예상 기술적 문제

| 문제 | 대응 |
|---|---|
| Recharts에서 공백 구간 표시 | 수집 간격 기준(예: 예정 주기의 2배)보다 벌어진 지점에 `null` 포인트를 넣고 `connectNulls={false}`. 이 null은 **화면용**이며 DB에는 저장하지 않는다 |
| 변형이 많을 때 그래프가 복잡함 | 기본은 선택한 변형 1개, "다른 변형 겹쳐 보기"는 최대 3개 |
| 서버 렌더링과 차트 hydration | 차트 컴포넌트만 `dynamic(…, { ssr: false })` 또는 `'use client'` |
| 시간 축 시간대 | 차트 축은 KST로 포맷 |
| 수치가 많은 요약 카드의 모바일 표시 | 2×2 그리드로 접힘 |

## 7. 테스트 및 검증 기준

- [ ] 샘플 시드의 각 시나리오([database.md §7](database.md#7-마이그레이션과-시드))가 화면에서 의도한 상태 배지로 표시된다
- [ ] 데이터 부족 상품에서 30일·90일 칸이 숫자가 아니라 "데이터 부족 · N일 수집"으로 표시된다
- [ ] 그래프 공백 구간에서 선이 이어지지 않는다
- [ ] 샘플 데이터가 있는 화면에 샘플 배너와 배지가 표시된다
- [ ] 수동 입력 폼이 미래 시각, 0 이하 가격, 정가보다 큰 판매가를 거부한다
- [ ] 화면의 모든 가격 수치가 DB 검증 SQL 결과와 일치한다
- [ ] 상태 배지가 색상 없이(흑백)도 텍스트로 구분된다
- [ ] 1280px(노트북)과 1920px(PC)에서 레이아웃이 깨지지 않는다
- [ ] AI 해석 카드가 가격 요약 카드와 시각적으로 구분되고, 근거 데이터 범위가 표시된다 (P2)
