# 플랫폼 정책 검토: 무신사

> 검토일: 2026-11-18 · 절차: [architecture.md §6](../architecture.md#6-데이터-수집-정책-검토-절차)
> 결론: **`collection_mode = manual`** — 자동 수집(크롤링) 하지 않음

## 1. 공식 API · 제휴 피드

- 외부 개발자용 공개 상품·가격 API를 찾지 못했다.
- 확인된 공식 도구는 입점 브랜드용 앱(MUSINSA PARTNER)뿐이며 외부 개발자용이 아니다.
- 검색에 나오는 무신사 수집 도구는 모두 제3자 스크래퍼(Apify 등)로, 무신사가 허용한 경로가 아니다.

## 2. robots.txt (2026-11-18 확인)

- `User-agent: *` → `Disallow: /` — 명시된 약 30개 봇(검색엔진·소셜 미리보기 등)을 제외한 **모든 봇의 사이트 전체 수집 금지**.
- 상품 페이지(`/products`, `/app/goods`)와 API 경로에 대한 별도 허용 규칙 없음.
- 이 프로젝트의 서버에서 robots.txt 요청 자체가 Cloudflare 봇 차단에 걸림 ("Sorry, you have been blocked").

## 3. 이용약관

- 원문의 자동 수집 관련 조항은 이번 검토에서 확인하지 못했다. 확인되면 이 절에 조항과 확인 날짜를 추가한다.

## 4. 로그인 필요 가격

- 회원가·쿠폰가가 존재한다. 비교 기준은 로그인 없이 보이는 판매가로 고정한다 (PRD F3-2).

## 5. 결론과 근거

| 결정 | 근거 |
|---|---|
| 자동 수집 구현 안 함 | robots.txt 전체 금지 (PRD §6 결정 규칙 2) |
| 차단 우회 안 함 | 자동 접근에는 Cloudflare 차단 우회가 필요함 (PRD §6 결정 규칙 3) |
| 수동 입력으로 운영 | PRD §6 결정 규칙 5 |
| 개인용·과제용이어도 동일 | robots.txt·약관은 사용 목적과 무관하게 적용되고, 차단 우회는 목적과 무관하게 법적 위험이 가장 큰 부분임 |

## 6. 대체 수단

1. **수동 입력** — 사용자가 확인한 가격을 직접 기록 (`source = manual`).
2. **북마클릿** — 사용자가 브라우저로 보고 있는 상품 페이지 1개의 표시 가격을 사용자가 버튼을 눌러 기록. 봇 접근·반복 요청·차단 우회가 없다. 기록 출처는 `manual`.
3. **네이버 쇼핑 검색 API** — 공식 API로 자동 수집. 상품 단위 최저가만 제공(옵션별 가격 없음). 별도 검토 문서에서 약관·호출 한도를 확인한 뒤 도입한다.
4. **무신사 정식 문의** — 데이터 제공·제휴 허락을 받으면 그 범위 안에서 재검토한다.

## 7. 재검토 조건

- 무신사가 공식 API·제휴 피드를 제공하거나 서면 허락을 받은 경우
- robots.txt 가 변경된 경우 (검토 시 날짜와 함께 이 문서를 갱신)
